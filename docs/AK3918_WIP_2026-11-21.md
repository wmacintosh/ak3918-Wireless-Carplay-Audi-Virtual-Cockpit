# AK3918 Audi Virtual Cockpit — Experimental Development

Status: Work in progress, November 21, 2026.

## Objective

Restore wireless CarPlay rendering in the Audi Virtual Cockpit
while preserving the working center MMI display.

## Source changes

- Repaired earlier HTTP message ownership handling.
- Removed unsafe writes to stock connection-ID globals.
- Removed detached-worker access to the unowned AirPlay client.
- Integrated experimental stream type 111 with stock stream 110.
- Added response handling while retaining the stock callback.
- Added session-generation and teardown protections.
- Revised combined-stream array construction to avoid CoreFoundation
  operations while holding the session-state lock.
- Disabled independent asynchronous cluster HTTP retries.

## Validation completed

- Verified original firmware recovery SHA-256.
- Verified original ARM hook instructions and callback addresses.
- Compiled experimental ARM/uClibc modes 0 and 1.
- Verified experimental ELF branch targets and trampoline locations.
- Applied the Step 112 source correction.
- Passed Step 113A ARM compilation and ELF checks.
