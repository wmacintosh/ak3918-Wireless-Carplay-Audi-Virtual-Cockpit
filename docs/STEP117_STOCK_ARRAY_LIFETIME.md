# Step 117 — Stock local array ownership (read-only disassembly)

## Input

`AK3918_step117_full_ownership.txt`, generated by cross-architecture objdump from stock `sdDongle` with SHA-256 `b2e32b82a37667500ca4f1c8266604bf28cc923ac94343907eb68c843d92e0a1`.

## What the stock code demonstrably does

- `0x2f6b8`: native outgoing-screen SETUP function entry.
- `0x2f6d8`: zeros `[sp,#0x34]`, which is its stack-local stream array pointer.
- `0x2fad4`: loads stock stream 110 dictionary into `r1`.
- `0x2fad8`: supplies address of `[sp,#0x34]` as the array slot.
- `0x2fadc`: invokes `0x9327c`, the array ensure helper.
- `0x9327c..0x93318`: helper creates a mutable CF array via `0x82e10` if the slot is null, stores the resulting pointer, then appends the stream using `0x82fc0`. The newly created array appears to be held as the caller-local owned reference.
- `0x2fae0`: reloads the array pointer from `[sp,#0x34]`.
- `0x2faec`: calls `0x836dc` to set that array in the request dictionary; entrypoint branches to `0x885f8`, which is **not** disassembled in the Step 117 report.
- `0x2fe1c..0x2fe28`: stock cleanup fetches the same stack-local array pointer and releases it through `0x82c78`.
- `0x2fe2c..0x2fe38`: stock cleanup separately releases the HTTP message object if present.

## Implication for Step 112

The Step 112 strategy of building a fresh, owned mutable CF array and replacing the local pointer aligns with the native function's expected ownership shape. The displaced original reference would otherwise not be released by native cleanup, since cleanup reads the **replaced** pointer. Releasing `replaced_streams` after swapping is therefore **consistent with local-reference accounting**, assuming the array and element callback signatures were correctly reverse engineered.

The report does not establish whether `0x885f8` retains the array in the request dictionary, or whether any other implementation-specific ownership conventions affect the result. Retain semantics must be checked before treating the swap as runtime-verified.
